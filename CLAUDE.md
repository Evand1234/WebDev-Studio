# WebDev Studio (BrandMasters)

This repo is the permanent memory for all of Evan's web dev work. A fresh session should be able to start from here with nothing else.

## Before you do anything
1. Read `firstcheck.md` and follow every rule in it. It overrides everything else.
2. Read `web-dev-context/README.md`, then the files it tells you to read for your task.

## Layout
- `firstcheck.md`: Evan's must-follow rules.
- `web-dev-context/`: everything about the business, Evan, the design direction, the tech rules, 21st.dev references, history and lessons.
- `archive/v2-static-site/`: the V2 site from 18 Oct 2026. Evan rejected it. Reference only, do not build on it.
- `archive/v3-cloud-site/`: the Next.js site built in the cloud on 18 Oct 2026. Evan found it bland and it skipped the plan. Reuse its plumbing if useful, not its look.
- `ref-study/`: screenshots and notes of Evan's taste references.
- `plans/` and `demos/`: planning boards and small demos shown to Evan.
- New site builds go in their own folder (for the BrandMasters site: `site/`), so context and code stay apart.

## Keeping this memory alive
When Evan decides something new, or you learn something a future session would otherwise have to rediscover, update the right file in `web-dev-context/` in the same change. Keep files short and current; delete what turns out to be wrong. Never put secrets, passwords or API keys in this repo.
